# Komentář k zákonu č. 416/2009 Sb., o urychlení výstavby strategicky významné infrastruktury

Otevřený komentář k zákonu o urychlení výstavby strategicky významné infrastruktury — § po §: doslovné znění, výklad, kazuistika, protiargumenty a praktický závěr; zvláštní postupy přípravy a povolování dopravní, energetické a další infrastruktury, oprávněný investor a mezitímní rozhodnutí, projekty společného zájmu, transevropská dopravní síť a údolí pro technologie pro nulové čisté emise.

Konsolidované znění: dokument e-Sbírky `SB-2009-00416_2026-01-01`.
